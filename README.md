Taller de Preparación para IJIO (G7-G12)
Bienvenidos al Taller de Preparación para IJIO dirigido a estudiantes de grados G7 a G12. Este espacio está pensado para desarrollar pensamiento lógico, programación en Python y resolución de problemas, que son bases clave en la preparación para olimpiadas y concursos de informática.

Propósito
El taller busca que los participantes aprendan a programar desde cero o fortalezcan sus bases para resolver problemas algorítmicos con claridad, precisión y buena estrategia. La preparación en olimpiadas de informática comienza con la programación y continúa con el desarrollo de habilidades de algoritmia, práctica constante y análisis de problemas.

Público objetivo
Este taller está diseñado para:

Estudiantes de grado 7 a grado 12.

Participantes con nivel principiante, básico o intermedio.

Estudiantes interesados en Python, lógica, matemáticas y concursos de informática.

Objetivos de aprendizaje
Al finalizar el taller, cada participante deberá ser capaz de:

Comprender la sintaxis básica de Python y escribir programas simples.

Resolver ejercicios con variables, entradas, salidas, condicionales y ciclos.

Usar listas, funciones y operaciones básicas para resolver problemas.

Aplicar lógica computacional para analizar enunciados y construir soluciones paso a paso.

Practicar estrategias de resolución usadas en concursos escolares de informática.
